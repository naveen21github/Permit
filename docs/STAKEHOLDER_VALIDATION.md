# Stakeholder & User Validation Protocol

> **Synthetic Scenario Validation Walkthrough**

---

## 1. Stakeholder Core Validation Questions

| # | Question | Prototype Capability & Answer |
| :- | :--- | :--- |
| **1** | *Who currently owns this application?* | Visible on application card header (e.g. `Engineer Bob Smith - Traffic Manager`). |
| **2** | *Which department has it?* | Clear status badge & active department label (`Traffic Management & Engineering`). |
| **3** | *Why is it delayed?* | Explicit controlled delay reason & justification note (`Awaiting signal control clearance`). |
| **4** | *What happened previously?* | Full timestamped chronological event timeline audit log. |
| **5** | *Can field staff capture data offline?* | Yes, offline mobile form saves to local queue with one-click background sync. |

---

## 2. Validation Findings & Feedback

* **Observation 1:** Stakeholders confirmed that making handoff acceptance explicit eliminated disputes over lost applications between Traffic Engineering and Field Safety.
* **Observation 2:** Department directors praised the non-surveillance focus, confirming staff adopt systems faster when delay tracking identifies resource constraints rather than scoring employee speed.
