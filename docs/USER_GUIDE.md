# User Guide: Cross-Department Permit Workflow Tracker

---

## 1. Creating a Permit Application
1. Click **+ New Application** in the top action bar or navigate to **Field Capture**.
2. Select the **Permit Type** (e.g. *Bus Stop Bay Relocation*).
3. Enter the **Route Reference** and **Applicant Organization**.
4. Click **Create Application**.

---

## 2. Checking Documents & Handing Off
1. Click an application card to open the **Detail Modal**.
2. Check the **Document Status** card. If missing documents exist, upload/verify them.
3. Once documents are verified, click **Initiate Department Handoff**.
4. Select the **Target Department**, **Target Role**, and enter the **Handoff Reason**.
5. Click **Submit Handoff Request**.

---

## 3. Logging & Resolving Delays
1. Inside the Detail Modal, click **Log Accountable Delay**.
2. Select a controlled reason (e.g. *Traffic coordination*).
3. Enter a mandatory justification note (at least 5 characters).
4. To resume review once clear, click **Resolve Delay**.

---

## 4. Offline Capture Mode
1. Click the **Online / Offline Toggle** in the top navigation bar to simulate field network loss.
2. Navigate to **Field Capture** and create an application.
3. Notice the application is saved locally with a `PENDING SYNC` badge.
4. Toggle network back **Online** and click **Sync Queue** to synchronize data with the main database.
